# пункт на 4 балла
Упаковала приложение в docker

## репо

- `app.py` — само приложение
- `Dockerfile` — инструкция, как собрать образ
- `.dockerignore` — что не надо класть в образ
- `logs.txt` — логи контейнера

## запуск

Сначала собираю образ:

```
docker build -t counter-app .
```

Потом запускаю контейнер. Порт 8080 на компьютере — это порт 8000 внутри контейнера. Приветствие передаю через переменную GREETING:

```
docker run -d --name counter -p 8080:8000 -e GREETING="pupupu" counter-app
```

## проверка

Сделала запрос на главную страницу, потом два раза увеличила счётчик и снова посмотрела:

```
curl -fsS http://127.0.0.1:8080/
curl -fsS -X POST http://127.0.0.1:8080/increment
curl -fsS -X POST http://127.0.0.1:8080/increment
curl -fsS http://127.0.0.1:8080/
```

Что получилось: счётчик был 0, потом 1, потом 2, и последний запрос снова показал 2. Приветствие в ответе стало "pupupu", значит переменная окружения работает.

## логи

Логи взяла командой:

```
docker logs counter > logs.txt 2>&1
```

В файле `logs.txt` видно, что приложение запустилось на порту 8000, и 4 запроса (GET, POST, POST, GET), все со статусом 200.
